# Musik_Maker

## Resumen

La idea para nuestro proyecto se debe a nuestro interés en hacer un programa realicionado con la música. Es por eso que a partir de nuestro conocimiento en programación sumado al conicimiento en el ámbito musical, decidimos hacer una herramienta pensada para guitarristas.

El programa va a permitir el ingreso de la letra de una canción seguido de todo lo necesario para poder tocar dicha canción en guitarra. Por ejemplo, el usuario contará con una lista de acordes básicos los cuales podrá incluir en la cancion. Ademas podrá crear sus propios acordes y guardarlos en la lista. En el caso de que la cancion tenga un solo de guitarra, se ingresarán las notas a modo de tablaturas al ser la forma mas simple en que un guitarrista puede entender.

El problema que queremos resolver es tener una forma simple de organizar una canción para poder estudiarla o tocarla. La idea es que el usuario pueda tener todo lo que necesita de una canción en un mismo lugar y modificarlo según la forma en la que quiera tocarla.

Nustra motivación principal para este proyecto fue principalmente el interez por la música y la programación, pudiendo combinar ambos conocimientos para desarrollar este programa y dar un aporte al mundo musical.
